# Changelog

All notable changes to Content Reset Tool are documented here.

## 1.0.0 — Initial Release

- Initial public release.
- Added administrator-only Content Reset interface.
- Added Content Only reset mode.
- Added Content + Media reset mode.
- Added standard post and page deletion.
- Added custom post type deletion.
- Added comment deletion.
- Added taxonomy cleanup.
- Added navigation menu cleanup.
- Added orphaned metadata and relationship cleanup.
- Added WordPress nonce verification.
- Added administrator capability checks.
- Added explicit `DELETE CONTENT` confirmation.
- Added destructive-action warning and confirmation dialog.
